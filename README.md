## Simple Interest Calculator

A simple calculator script written in Bash that calculates simple interest given principal, annual rate of interest, and time period in years.

### Formula
`Simple Interest = (P * T * R) / 100`

### Input:
- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

### Output:
- `simple interest`: Calculated simple interest value
